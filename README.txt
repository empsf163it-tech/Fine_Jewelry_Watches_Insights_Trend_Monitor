MAISON — LUXURY JEWELRY & WATCH INTELLIGENCE DEMO

HOW TO RUN
1. Extract this ZIP file.
2. Open index.html in a modern browser.
3. Internet access is required for the remote Unsplash image URLs.

CONTENTS
- index.html: standalone dashboard prototype with luxury watch and fine-jewelry items, product detail popups, filters, watchlist, monitoring rules, and CSV export.

IMPORTANT
This is a front-end demo. Trend values, price ranges, and alert signals are illustrative, not live data. Monitoring selections are kept in browser memory and are not persisted. Images are representative category photography and may not show the exact named product.
